## Implementation

The canonical and Spanish pages use the existing project layout, structured
director metadata, gallery/poster fields, language switcher, and sharing UI.
The taxonomy adds the film and bilingual Western/Thriller labels. The shared
media template now supports positioned Instagram posts in `projectVideos` and a semantic
poster figure with an optional `posterCaption`. These fields are editable in
Pages CMS. Instagram's official script loads once on pages that use it; a small
local helper supplies localized accessible iframe titles. Shared styles allow
the cards to fit narrow article columns. Existing YouTube/Vimeo output remains
on its established path.

Original supplied media remains on the Desktop. Extraction frames, fetched
reference images, build logs, and browser review output are local ignored
artifacts under `.artifacts/tecolote/`; optimized site JPEGs and the hover derivatives belong in
`src/img/`. WebP derivatives remain owned by the CI/staging pipeline.
