<p><em>The Dust Wave Show</em> es nuestra serie de antología producida para el acceso público local de Albuquerque. <a href="https://www.cabq.gov/artsculture/albuquerque-community-media/channels/local-origination-channel-26">Channel 26</a>. Cada episodio es una recopilación de películas creadas por miembros de Dust Wave. Segmentos de host filmados <a href="https://allthingsmood.com">MOOD</a> en Albuquerque, Nuevo México.
</p>
